方案要点

完整论述见 docs/design/ui-redesign-2026-09.md

首页从目录变行动面板

原首页 = Hero + 4 张科目卡 + 自定义题库卡 + 7 个快捷入口，四个并列视觉重心，用户必须自己判断"今天点哪个"。

新首页只回答一个问题：我今天该做什么。一个主按钮 + 三个今日任务 + 续接卡，其余全部下沉到「我的」。

导航按目标而非模块组织

原底部 Tab：首页 / 智能组卷 / 错题 / 收藏 ——「智能组卷」是任务不是区域，「收藏」低频，两者各占 25% 导航位。

新 Tab：今日 / 刷题 / 错题 / 我的。组卷并入刷题，收藏笔记并入错题。

错题从列表升级为闭环

引入掌握度模型：连续做对 2 次 → 已掌握；做错则重置。错题本顶部是掌握度环，底部是"一键重做待攻克"。

结算页的唯一主行动也是"去攻克错题"——把用户从「做完」推向「订正」。

AI 从设置项变上下文按钮

现状：AI 藏在设置页，首次使用要先填 API Key。

新方案：全局 AI 悬浮球按页面自适应 —— 题目页「问 AI」、申论页「批改」、错题页「错因归纳」、今日页「学习顾问」。

视觉：为什么换掉 iOS 系统蓝

现在的 #007aff + hairline 是无个性也无记忆点的系统默认观感，高饱和蓝色长时间阅读刺激强。

新方案用低饱和靛墨蓝做结构色，用朱批红建立独有的产品符号——看到红色就想到「这里错了，要订正」。

可落地：分 5 阶段，零构建改造

现有前端是零构建原生 SPA，可灰度替换：① 换 token（全站换皮，0 逻辑改动）② 改导航 ③ 重做核心页 ④ AI 上下文化 ⑤ 桌面双栏。

阶段 1 风险最低、收益最大，建议先行。
