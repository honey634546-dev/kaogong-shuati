# 提速复盘交付与验收

本次是 2026-09-27 用户指出入口缺陷后的本地修订。浏览器入口：http://127.0.0.1:3000 。使用现有本地账号、题库与 AI 设置，服务仅监听本机。未推送远程、未部署或改动线上服务。原版「点击后告知本功能不支持」不满足产品验收；原功能测试通过不能证明该设计合理。

## 验收操作

1. 刷新页面，完成普通练习或打开「练习记录」。只有存在可分析题时才展示「解题方法复盘」。全常识、政治或其他不适用卷直接保留原成绩、用时和解析。
2. 推荐只包含具备方法分析资格且超过参考用时的题；可输入统一秒数，或恢复题型参考。缺失用时、未答、无可核对答案、明确提前看解析的题不进入慢题候选。
3. 合格题在按钮旁显示题型与分析方向。点「分析解题方法」，可选填写卡点与原解法，点「AI 分析本题方法」。查看本题方法识别信号、操作步骤、正确性依据和使用边界。不支持题没有该入口，也没有事后告知不支持的复习卡。
4. 对应三类基础方法时，点「独立练一道新题」，作答后查看正误、用时与解析，再点「再练一道新题」验证题目变化。配套题只检查基础方法，不代表原题难度，也不计入原卷成绩。
5. 图形/图表引用、导入缺图标记、占位选项、缺失或争议答案在入口前排除。对合格题分析后新发现的题意/答案冲突，应指出具体待核对信息。没有更优方法时展示本题的具体稳妥解法。错误格式应失败并可重试，不展示未经结构校验的建议。

## 支持范围与题型识别

| 入口题型 | 分析方向 |
| --- | --- |
| 数量关系 / 数学运算 | 列式、代入、等价变形与减少计算步骤 |
| 完整文字资料分析 | 基期、增长、比例计算，统计口径与估算边界 |
| 言语理解 | 文段结构、语境和选项排除步骤 |
| 明确细类「逻辑判断」 | 条件整理、推导与排除顺序 |

这些入口承诺分析方法，不代表题目已被标为「有快解」。目前依赖逐题规范分类元数据；没有经过验证的语义细题型识别器。只有「判断推理」父类、未知/冲突分类，以及常识/政治、图形/类比/定义/数字推理等未开放类型都隐藏入口。三类程序练习是独立能力，只有生成了对应方法后才出现训练按钮。

只读当前本地题库的资格统计见 [capability-data-audit.json](capability-data-audit.json)：705 题中有 238 题满足输入与题型条件（数量 70、资料 15、言语 153）；340 题未开放类型、127 题缺图。此统计不是 238 道题已验证有快解，也没有把用户题目发送给外部模型。

## 已交付行为

- 当前和历史共用资格规则，题卡入口、题型标注、推荐集合、服务端和本地模式一致；参考线公开、可调整。单个显式请求才调用模型，无整卷后台消耗。
- 历史使用本人当次题目版本、答案与计时快照；重复同题使用 submissionKey 精确定位。拒绝跨账号、失效练习和版本错配。
- 同组小问的快照保存作答时实际展示的共享材料、图片与缺图标记；后续材料编辑不改变该快照。避免当前无入口、历史却因材料丢失重新出现入口。
- 页面隐藏不再累计逐题解题/解析时间；考试总倒计时照常。首次提交或看解析仍终止初答计时。手动暂停和草稿纸回归通过。
- 提前看解析、在作答前获得随题辅导响应会保留 assisted 标记；历史不追溯推断未记录的辅助。没有记录辅助不能证明未接受外部帮助。
- 服务端 Key、浏览器 Key、本地模式采用统一任务提示词和输出约定；普通 AI 解析、其缓存和用户保存的模型配置不被覆盖。
- 新增方法练习：百分数分数互换、增长基期还原、比例比较；程序计算答案，不接受模型任意生成的答案键。

## 已知边界

- 首版参考秒数是可调整的产品初值，尚未通过学习效果实验校准，也没有伪造同难度群体平均数。
- 文字建议仍为 AI 建议；评估规模仅 20 个合成样本，不能代表所有题目。尤其用户没有原解法时，不能准确归因慢在哪里。
- 评估曾发现常识题解释有概念错误，失败记录保留。对明确常识/政治理论题隐藏本功能入口且不调用模型；合格文字题才提供 AI 候选方法。未声称 20 个样本所有原始模型输出都合格。
- 图片题、缺图标记、答案缺失或已知争议在入口前排除。未人工确认的导入参考答案允许方法分析，但要求模型独立核验，不伪称人工已核验教材。
- 训练结果在当前页面显示；未建立跨日方法掌握档案，也没有实证证明用户长期提速。需要后续在没见过的相近新题上观察正确率和用时，并延迟复测。
- 历史计时没有完整后台/中断信息，不能追溯校正；自述中断可以帮助 AI 解释，但不会伪造干净的计时记录。
- 旧版本已经遗失共享材料、且未保存材料归属的历史快照，本轮没有推测回填；不能宣称所有过去材料已恢复。共享材料修复保护新生成的快照。
