# 提速复盘交付与验收

本次是首版本地交付。浏览器入口：http://127.0.0.1:3000 。使用现有本地账号、题库与 AI 设置，服务仅监听本机。未推送远程、未部署或改动线上服务。生产主机与当前发布命令未在仓库中找到可验证配置，不将本地运行描述为线上发布。

## 验收操作

1. 登录后完成一次普通练习，或在「练习记录」打开已有练习。成绩页新增「提速复盘」。
2. 查看用时超过练习参考线的题；可输入统一秒数，或恢复题型参考。缺失用时、未答、无可核对答案、明确提前看解析的题不进入慢题候选。
3. 点候选题或题目下方「提速复盘」，可选填写卡点与原解法，点「AI 分析本题方法」。查看方法识别信号、操作步骤、正确性依据和使用边界。
4. 对应三类基础方法时，点「独立练一道新题」，作答后查看正误、用时与解析，再点「再练一道新题」验证题目变化。配套题只检查基础方法，不代表原题难度，也不计入原卷成绩。
5. 图形/图表无法可靠读取、答案冲突或信息不足时，应看到不足信息说明。没有明显更优方法时应给常规建议。错误输出应失败并可重试，不展示未经结构校验的建议。

## 已交付行为

- 当前和历史复盘共用一个入口；参考线公开、可调整。单个显式请求才调用模型，无整卷后台消耗。
- 历史使用本人当次题目版本、答案与计时快照；重复同题使用 submissionKey 精确定位。拒绝跨账号、失效练习和版本错配。
- 页面隐藏不再累计逐题解题/解析时间；考试总倒计时照常。首次提交或看解析仍终止初答计时。手动暂停和草稿纸回归通过。
- 提前看解析、在作答前获得随题辅导响应会保留 assisted 标记；历史不追溯推断未记录的辅助。没有记录辅助不能证明未接受外部帮助。
- 服务端 Key、浏览器 Key、本地模式采用统一任务提示词和输出约定；普通 AI 解析、其缓存和用户保存的模型配置不被覆盖。
- 新增方法练习：百分数分数互换、增长基期还原、比例比较；程序计算答案，不接受模型任意生成的答案键。

## 验证证据

`npm run test:speed-review`：23 项通过（11 核心、9 API/存储/身份与多运行路径、3真实浏览器流程）。核心包含 3 种题型各 250 个种子的独立数值核验，共 750 道。

`AUTH_DISABLED=1 node --test test-wp3-attempts.mjs test-scratchpad-model.mjs test-scratchpad-e2e.mjs test-rich-text.mjs`：9 项通过。另相关 AI/Key/本地记录/随题辅导/自定义分组回归 32 项通过。根目录缺少私有 `tiku.db` 的旧 `test-custom-practice.mjs` 无法加载其夹具；未宣称全仓库测试全部通过。

浏览器协议测试截图位于 `screenshots/mobile-review.png` 与 `screenshots/desktop-dark-review.png`，这些截图使用 HTTP fixture 模型，不能当作真实模型质量证据。

真实模型质量：见 [EVALUATION.md](EVALUATION.md)。保留首轮失败与修正后的逐例结果，结构、答案和教学文字分别审阅。原始题目均为合成样本；没有把用户真实历史提交到评估脚本。真实模型与页面联测的结果另见 `live-ui.json` 与 `live-mobile.png`、`live-desktop.png`：一次真实请求约 12.7 秒，0 页面异常，配套新题作答通过，临时服务与凭据库已清理。该测试显式注入 160 秒用于检查筛选，不代表真实学习耗时。

## 已知边界

- 首版参考秒数是可调整的产品初值，尚未通过学习效果实验校准，也没有伪造同难度群体平均数。
- 文字建议仍为 AI 建议；评估规模仅 20 个合成样本，不能代表所有题目。尤其用户没有原解法时，不能准确归因慢在哪里。
- 评估曾发现常识题解释有概念错误，失败记录保留。首版对明确常识/政治理论题只给固定复习步骤，不调用模型生成快解；其余文字题才提供 AI 候选方法。未声称 20 个样本所有原始模型输出都合格。
- 图片题保守降级；原题答案缺失或存在争议时先核对题库。未人工确认的导入参考答案允许复盘，但要求独立核验，不伪称官方答案。
- 训练结果在当前页面显示；未建立跨日方法掌握档案，也没有实证证明用户长期提速。需要后续在没见过的相近新题上观察正确率和用时，并延迟复测。
- 历史计时没有完整后台/中断信息，不能追溯校正；自述中断可以帮助 AI 解释，但不会伪造干净的计时记录。

## 复现

```sh
npm run test:speed-review
npm run evaluate:speed-review
# 可选：使用现有配置进行真实模型调用，产生实际用量。
node scripts/evaluate-speed-review.mjs --live
# 单例真实模型与浏览器联测，临时测试账户/数据库结束后删除。
node scripts/verify-speed-review-live-ui.mjs --live
# 本地验收服务
APP_DATA_DIR="$PWD/data" HOST=127.0.0.1 node server.mjs 3000
```

Android 的 `webDir` 指向整个 `public/`，新模块随常规 Capacitor 同步复制；本次没有构建/签名 APK，也未进行真机验收。
