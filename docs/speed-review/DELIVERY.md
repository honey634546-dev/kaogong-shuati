# 解题方法复盘：本地交付与验收

2026-09-27，针对“缺少细类标签导致已导入判断题全部不能用”的修订。验收地址：http://127.0.0.1:3000 。使用现有本地账号、题库与 AI 设置；服务仅监听本机。未推送远程或部署线上。

## 当前行为

缺少细分类不再等于无法分析。完整文字判断题可直接分析条件和选项；能可靠辨认结构时标出定义、类比或逻辑，并注明「题面识别」。不能确定细类时显示「文字判断」，不会要求用户先补标签，也不会打开后再说该父类不支持。

| 类型 | 方法分析方向 |
| --- | --- |
| 数量关系 / 数学运算 | 列式、代入、等价变形与减少计算 |
| 完整文字资料分析 | 基期、增长、比例、统计口径与估算边界 |
| 言语理解 | 语境、文段结构和选项排除 |
| 逻辑判断 | 条件整理、推导顺序与排除 |
| 定义判断 | 拆分必要条件、逐项匹配、核对肯定或否定问法 |
| 类比推理 | 词项关系、前后方向与层级 |
| 仅有判断推理父类的完整文字题 | 按题目实际条件和选项选择方法 |

以上是候选方法分析范围，不表示每道题有快解。常识/政治、依赖图像、未识别且无可用父类、分类冲突、缺材料或答案仍没有方法入口。不存在更优解法时，分析应给出本题具体的稳妥做法，不能用泛泛“多练习”替代。

## 现有题库效果

只读六份原卷缓存、标准化数据和当前库：原分类均被保留，但220道判断题的来源只给父类，重新导入不能获得不存在的逐题细标签。当前题库705题的方法分析资格由238题增加至406题。

新增的168道判断题中：定义42、类比42、逻辑36、保留父类的文字判断48。另52道判断题全部含明确缺图标记；这是题目内容不完整，补一个分类标签无法修复。

分类在读取题目时派生，旧题和旧形状历史快照立即适用，不改写题目原分类、身份、指纹或版本。新 AI 导入保留原文已有细类，结构足够明确时可以填细类，不确定时保留大类；题目编辑器也会保留完整分类路径。没有后台批量 AI 分类用量，没有修改用户保存的模型配置。

[最终代码只读汇总](classification-data-audit-final-v2.json)确认上述覆盖数。[此前冻结的独立分类抽查](classification-data-audit-v1.json)：36道事先独立标注题中，程序给出的24个细类与标注一致，12道保留父类；27道完整文字题全部可用，9道图形题全部排除。标注来自独立代理而非领域专家，小样本一致率不代表任意未来试卷的准确率。后续独立代码审查补齐了导入提示中三个明确图形模板的缺图守卫，没有用盲标结果调参后重报准确率。

## 验收操作

1. 刷新页面，完成普通练习，或打开已有「练习记录」。有合格题时显示「解题方法复盘」，仅推荐超过练习参考用时且计时可用的题。
2. 在判断题下查看题型、分析方向和「分析解题方法」按钮。父类题显示「文字判断」，自动细分题另有「题面识别」标记。
3. 打开后可直接点「AI 分析本题方法」，也可先填写卡点或原解法。没有自述时，用时线索显示固定的两句提示，不让模型猜个人慢因或输出调试字段；填写后才显示依据自述的建议。
4. 核对本题方法、具体步骤、正确性依据与适用边界。没有支持的基础练习时不显示练习按钮；百分数分数互换、基期还原、比例比较三类可以独立练一道程序验算的新题。
5. 缺图题与常识题不出现方法入口；原用时和题库解析仍可看。当前和历史采用同样规则。

## 边界

- 自动细分使用保守结构规则，不保证识别所有表达；保留父类时完整文字判断仍可用。`source`表示题库已有分类，也可能来自此前AI导入，不能说成原卷或人工已验证。
- AI方法建议仍可能出错。样本检查不证明每题都有捷径，也没有证明用户长期正确率和速度改善。
- 用时参考是可调整的产品初值，不是同难度考生平均值；没有解题过程无法准确归因慢在哪里。
- 历史沿用本人当次题目快照与计时；早期未记录的中断、辅助或已丢失材料不能追溯猜测回填。
- 根目录缺少私有 `tiku.db`，部分旧全仓测试不能运行；本轮相关测试使用隔离夹具，未宣称全仓 `npm test` 通过。未构建/签名Android APK或进行真机验收。

```sh
node scripts/evaluate-method-classification.mjs
# 只读本机统计，无模型用量；盲标文件仅保存在本机忽略目录。

```
