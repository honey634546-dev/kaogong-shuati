# 做题后提速复盘

## 目标与授权

用户于 2026-09-27 授权负责调研、评估、方案、实施、验证与交付，仅在最后验收。目标是在正确率不下降的前提下改善独立解题效率；生成技巧或重复原题变快均不代表目标已经达成。

## 决策

首版采用「透明的慢题筛选 → 本题方法与边界 → 可验算的新题练习」。筛选不用模型猜：按题型提供可调整的练习参考时间，不声称是同难度人群均值。数量 120 秒、资料 90 秒、判断 90 秒、言语 75 秒、常识 30 秒、未知 90 秒，均为初始产品参数，尚未经效果实验验证。用时只代表初答前页面停留；缺失、无答案、未答、显式受辅助的数据不作为可靠慢题。共享材料提醒首次阅读成本。

保留首次提交/首次看解析终止计时的行为；隐藏页面停止逐题计时，考试总倒计时继续。学习解析不算做题时间。历史计时不追溯修正。

结果页和历史记录先判断题目是否具备方法分析资格，合格题才有「分析解题方法」入口，并在入口旁标出题型和分析方向。只有合格且计时可用的慢题进入推荐；全卷没有合格题时不展示方法复盘模块，原有逐题用时、题库解析继续显示。用户可调参考秒数并可选说明卡点、原解法。不自动整卷调用模型。复用现有模型连接，但使用独立任务提示词，允许没有捷径；不改变普通解析与做题中的启发辅导。完整题面、选项、材料、参考答案、用时和用户自述作为数据，不能覆盖任务约束。

输出必须是结构化内容：方法名、识别信号、操作步骤、正确性依据、适用范围、限制、审慎诊断。缺图/信息不足时不猜。独立服务端快照与用户隔离优先；不污染现有解析缓存。浏览器 Key 和本地模式保持相同协议。

方法练习只对百分数分数转换、基期还原、比值比较提供程序生成与验算的题。其他合格题可获得候选方法建议，但不伪造未经校验的训练题。新题提交前不显示答案；提交后显示正误、实际用时与解析，不把一次练习标成「已提速」。练习用于即时检验，不计入原卷成绩。

## 2026-09-27 用户验收发现与修订

用户指出：已知不支持的常识题仍有「提速复盘」按钮，点入后才说不支持，入口与实际能力不符。问题成立。原测试覆盖调用、输出、练习和计时，却没有覆盖入口资格；此前没有真人可用性研究，不能称设计已经过用户验证。此反馈是一个真实的可用性缺陷，不能用测试通过否定。

修订将四件事分开：有效用时超过参考线、识别题目结构、题目满足方法分析资格、模型实际找到候选方法。前三者均不能证明第四者。程序可验算的三类练习是另一项能力，不能充当所有 AI 建议的质量证明。

| 可识别范围 | 分析方向 | 入口条件 |
| --- | --- | --- |
| 数量关系 / 数学运算 | 比较列式、代入和计算步骤；检查等价变形 | 明确分类、完整文字题、答案可核对 |
| 资料分析 | 比较基期、增长、比例等计算；检查统计口径和估算条件 | 必要数据已提供为文字，不能依赖未读取的图表 |
| 言语理解及其明确细类 | 文段结构、语境、选项依据与排除顺序 | 仅承诺方法分析，不标「有快解」 |
| 逻辑判断 | 条件整理、推导和排除步骤 | 原分类明确，或题面具有完整条件与明确推导设问 |
| 定义判断 | 拆分必要条件、逐项核对、核对肯定或否定设问 | 原分类明确，或完整定义段与根据定义判断的设问同时出现 |
| 类比推理 | 固定关系、词项方向与层级 | 原分类明确，或题干和各选项均符合词语关系组结构；数字比例等反例除外 |
| 仅有判断推理大类 | 显示「文字判断」，按实际条件和选项选择方法 | 完整文字题即可，不要求先确定细类，不承诺有捷径 |
| 常识 / 政治、图形 / 数字推理、申论 | 本功能没有足够覆盖证据 | 隐藏入口；保留普通用时与解析 |
| 无法识别且无可用父类 / 冲突分类、缺图、占位选项、缺失或争议答案 | 不能安全形成具体方法分析 | 隐藏入口，不把范围拒绝包装成教学结论 |

分类优先使用逐题元数据及规范路径；只有父类判断或缺少有效分类时，才使用保守的题目结构规则补充定义、类比、逻辑细类。页面为结构推导结果标明「题面识别」。批次名称、题面出现单个「政治」「增长」「定义」等词不能作为分类依据；父类与子类须一致，冲突不自动覆盖。旧的非自定义题库可使用精确章节名，不能从自由命名的批次猜类型。这是有限结构识别，不是已经验证可覆盖所有试卷的语义分类器。

用户进一步指出：现有导入题仅有大类，把细类设为入口前提会使整批判断题无从使用。核查六份缓存原卷、标准化导入与当前库后，220道判断题的来源本身只有父类，705道现有题的原分类均保留，没有可重新导入恢复的逐题细类。因而撤回「父判断一律隐藏」的上一版设计。方法分析需要完整条件，不一定需要精确的题型名字；细分类用于优化分析方向，不能代替内容完整性检查。

旧题与历史快照在读取时派生分类，不改写原 category、question_uid、fingerprint 或 revision，避免重复导入被误判为题目修改。新 AI 导入临时追加分类保存约定，保留原文细类或可判断的细类路径，不确定时保留父类；文本、图片、服务端 Key、浏览器 Key 与本地模式共用约定。用户保存的模型配置不被重写。编辑器保留任意既有分类路径，防止打开编辑后分类丢失。

同一个 `getSpeedReviewCapability` 用于题卡、候选榜、服务端与本地 AI 路径。输入守卫同时检查图片引用、题干/材料/选项中的 HTML 或 Markdown 图片、导入器的三种明确缺图标记、显式缺图字段、空题面和字母占位选项。资格拒绝返回 `unavailable`，不调用模型、不生成泛泛复习卡。`no_shortcut` 仅用于已分析的合格题，仍须说明本题的稳妥解法。模型进一步发现题意或参考答案冲突时可以返回待核对内容，不能提前保证每道合格题都有捷径。

独立审查补充发现共享材料历史遗失问题：组内后续小问的原始行可能没有材料，但练习时继承组首材料。快照须冻结同批次同组当前材料及其图片/缺图标记，而不是保存空的原始行；显式需要共享材料却没有可读正文的题也不能显示入口。服务端与本地均按相同规则处理，正反例检查当前与历史一致。

只读审计当前题库：705道题的方法分析资格由238道增加到406道，判断题由0/220增加到168/220（结构细分120道，保留父类48道）；另外52道判断题均有明确缺图标记。36道独立事先标注的本地样本中，程序给出的24个细类与标注一致，12道保留父类；27道文字题全部可用，9道图形题全部被排除。独立标注来自另一个代理，不是专家金标准，不能把小样本一致率外推为通用准确率。未根据这些保留父类的样本调整规则后重算成绩。汇总见 classification-data-audit-v1.json，不包含真实题文。历史合成评估与失败记录保留，不通过覆盖报告掩盖缺陷。

## 排除的方案与范围

纯慢题排行加通用建议缺少可验证价值。自动草稿识别、同难度群体统计、跨日学习效果实验超出首版数据基础。首版不承诺准确诊断心理过程，不估算「能省多少秒」，不强制每题使用技巧，不在无可靠图像数据时推理图形内容。

## 验证与交付

1. 核心单测：空值/异常计时、参考线与题型、辅助状态、严格输出解析、三类练习多种子验算。
2. API 集成：临时数据库、身份隔离、历史快照优先、计时送达、畸形输出、各类资格拒绝无模型调用、浏览器与本地模式。
3. 浏览器：真实练习到成绩页、筛选与调整、提交可选卡点、成功/失败/重试、新题答前不泄题、历史回看、手机与桌面布局、暂停与隐藏计时；新增混合卷/全部不支持卷/缺图与未知分类负例，检查入口、标签和榜单一致以及普通解析仍可用。
4. 质量评估：20 道合成代表题离线验证；可用的真实模型进行有限调用，记录其结果，协议 mock 与真实质量分别报告。真实用户是否持续提速留待验收后的独立新题与延迟复测，不能用功能通过代替。
5. 交付：代码、测试、模型评估与页面截图、可打开验收地址、使用说明、已知限制、独立代码审查。

- [2026 国考公共科目考试大纲（政府网站转载）](https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml)：考试题型大类提供分类框架，不证明各类都有快捷方法。本产品另行按输入与评估证据限定能力。
- [GitHub Primer：Links and buttons](https://primer.style/accessibility/design-guidance/links-and-buttons/#buttons-2)：当前流程实际不可操作的控件应隐藏；适合禁用的通常是用户能立即补齐条件的控件。这里用户不能改变本题类别，因此采用隐藏。
- [NNGroup：Button States](https://www.nngroup.com/articles/button-states-communicate-interaction/)：按钮的可用状态和文案应建立准确动作预期。以上是设计依据，不是本项目的真人可用性测试。
- 当前项目已有 costMs、explanationMs、历史题目快照与 AI 讲解；原 AI 请求未传计时，也未获得用户解题过程。
- https://www.nature.com/articles/s41598-025-97652-6 ：大学物理结构化辅导随机试验支持研究可行性，但并不证明本应用的行测提速效果。
